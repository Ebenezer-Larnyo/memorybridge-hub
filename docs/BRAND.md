# Naviboa brand transition

Working brand adopted: Naviboa Hub (formerly MemoryBridge Hub). Companion: Naviboa AI (formerly Mira). Tagline: Guiding care. Connecting lives.

Name rationale: coined from navigation and inspiration from Akan Boafo (helper/supporter). This is a coined brand, not an Akan translation.

Visual identity: original compass/bridge navigation motif, deep purple (#5a2e85), lavender (#efe6f8), plum text (#2d2038), warm gold (#e3c38c), and a soft lilac background (#f8f5fc). The interface offers Lavender, Soft Pearl, and Midnight Plum modes, distinct from Spectrum Hub. These colors refer to the Alzheimer's awareness movement, without using the Alzheimer's Association logo or implying affiliation.

The current public URL and repository slug remain unchanged for continuity. Do not rename the GitHub repository or set a custom domain without a migration plan and verified domain ownership. Legacy technical identifiers (DOM IDs, local storage key, crawler user agent, Worker service name, test environment variable names and documentation paths) remain stable to avoid breaking existing user preferences, robots directives, pilot integrations and external links.

The name was preliminarily screened but not legally cleared. Do not represent the mark as registered or use the registered mark symbol. Before wider commercialization or filing, verify exact and similar marks, relevant goods/services, ownership and domain availability.

This change does not alter the research prototype's nonclinical status, MIT license, resource data, cloud pilot activation state ; the crawler cadence is daily.
